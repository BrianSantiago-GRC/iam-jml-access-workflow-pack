# Offboarding Checklist

Date: 2026-05-16  
Use: Track required access-removal tasks at separation.

## Identity and Access Removal

- [ ] Disable user account at required time
- [ ] Reset active sessions / revoke refresh tokens
- [ ] Remove group memberships
- [ ] Remove privileged/admin roles
- [ ] Disable VPN access
- [ ] Disable SSO-enabled application access

## Data and Ownership Tasks

- [ ] Transfer mailbox ownership (if needed)
- [ ] Transfer shared drive/document ownership (if needed)
- [ ] Confirm handoff for critical team files

## Device and Asset Tasks

- [ ] Confirm company device return status
- [ ] Confirm MDM status and lock/wipe if needed

## Verification and Closure

- [ ] Validate no active access remains
- [ ] Record ticket ID and completion date
- [ ] Attach evidence reference(s)
- [ ] Manager confirmation received
